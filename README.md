# Data Analytics Learning Journey

A public log of my move into data analytics: small, finished practice tasks first, then six larger projects. Every task starts with a business question, states the grain of the data, lists data quality problems, and says what the data cannot answer.

## Plan
About 15 months: 31 mini tasks and 6 projects across seven phases (foundations, Excel, SQL, Power BI, Python, end-to-end workflow, forecasting). Finished projects live in their own repositories. Task titles after Task 03 are planned topics and may change.

## Repo layout
One folder per phase (`00-foundations` to `06-forecasting`). Each task has its own folder with a `README.md`, a `screenshots/` folder and a `work/` folder with the Excel working copy.

## Data policy
CSV files are not committed. Excel working files are committed as proof of the work. Each workbook keeps the original data on its `raw` sheet, so a dataset is included only where its source license allows it. Each task README links to the original source.
